# deep-search-backend

A Django REST Framework based backend application to manage and track research sessions.  
This project exposes REST APIs to start research processes and store session details, with full admin panel support.

---

## 🚀 Features

- Django-based backend architecture
- RESTful APIs using Django REST Framework
- Research session management (create & view sessions)
- Admin dashboard for managing data
- SQLite database integration
- Clean and modular project structure

---

## 🛠 Tech Stack

- Python
- Django
- Django REST Framework
- SQLite
- Django Admin
